# 下一步试验计划：先定位对应损失，再比较参数

> 本文件保留试验前的冻结计划及当时“未测试”状态。2026-11-02已完成16轮有限对照；实际结果与未触发的条件试验见[实验结果](RESULTS.md)。`experiment_matrix.csv`仍保留试验前登记，实际逐轮记录见`results/analysis/round_results.csv`。

本文件是基于 `003015_7ea2c9` 原测试制定的计划。四份配置已准备并检查可读性；本轮没有执行新回放，没有推荐配置的实测收益。

## A. 先冻结比较条件

固定原 bag、5878 对输入、原始时间戳/序号/图像负载、1×回放、相同板端硬件与 CPU 策略、相同 ROS 队列及观察配置。每轮使用独立输出目录，从空 Atlas 开始，不读取上一轮地图。记录实际加载的节点/库 SHA、完整 YAML SHA、输入 SHA、温度、频率、RSS、后台任务和退出状态。

本次分析基于 `atomic_02` 冻结输入。若下一轮使用新的代码版本，须先记录提交、未提交补丁及实际加载二进制身份，并跑相同参数基线；不把不同版本的结果直接归因于参数。

同一个包只检验这个场景的改善。候选通过后，再选择另一段已有 D435i 数据或重新记录独立场景，检查是否只针对本包过拟合。

## B. 补充最低限度的观测与独立缺陷修复

| 观测位置 | 需要的计数/记录 | 要回答的问题 |
|---|---|---|
| Motion model / reference KF | 分支、BoW ready、初始匹配、优化后有观测的地图匹配、精确失败原因 | 33 次前端失败究竟卡在哪一步 |
| 局部地图搜索 | 候选总数、视锥内数、投影搜索数、描述子接受数、优化前关联数、优化后内点/外点 | 候选池增长后，是不可见、搜不到、描述子不通过，还是几何不通过 |
| 位姿优化 | 内外点深度分桶、残差/阈值分布、图像覆盖网格和预测像素误差 | 远点、集中分布或运动预测是否使约束失效 |
| 关键帧 | NeedNewKeyFrame 各条件、插入结果、队列长度、后台忙/BA中断 | 是否真正存在补图不足或后台阻塞 |
| 地图点维护 | 点 ID、出生 KF、年龄、可见/找到次数、观测权重、剔除原因；按批次聚合 | 初始种子如何退出，新增点能否存活 |
| 图像证据 | 固定输入窗口的真实投影/匹配/优化外点叠图 | 将现有离线两帧示意与真实 SLAM 关联对应起来 |

先只落轻量计数；真实匹配坐标和图像限定在事先选定窗口，缓冲后写盘，避免同步编码侵入关键路径。对观测关/开至少各做一次完整对照，若明显改变延迟或跟踪状态则先减小侵入，再做诊断结论。无观测帧必须保留空值。

修复空参考 BoW 时，应保证参考关键帧对前台可见以前 BoW 已完成，或通过明确的同步状态保证读取就绪。检查数据库插入和前后台访问，不能无同步地让多个线程写同一 BoW 容器。另将新图退出快照改成显式无效/已初始化元数据，避免继续读取默认 Frame 的未初始化 N/mnId。两类变更分别验证；不能因为记录改好了就宣称跟踪改善。

修复版与原版先用同一 P0 参数做交错对照，至少各两轮，记录第 674 帧所在固定窗口与全段质量。之后选定一个源码基线再进入参数矩阵。修复尚未执行；如希望先纯调参，也可在未修复版上完成矩阵，但必须保留 BoW 问题作为混杂因素。

## C. 第一轮参数矩阵：4 组、每组 2 次

| ID | 特征数 | 层数 | 要区分的作用 | 配置 |
|---|---:|---:|---|---|
| P0 | 700 | 5 | 原参数控制 | [P0_700_5.yaml](configs/P0_700_5.yaml) |
| P1 | 1000 | 5 | 单独增加候选特征 | [P1_1000_5.yaml](configs/P1_1000_5.yaml) |
| P2 | 700 | 8 | 单独扩大尺度覆盖 | [P2_700_8.yaml](configs/P2_700_8.yaml) |
| P3 | 1000 | 8 | 两者组合及相互影响 | [P3_1000_8.yaml](configs/P3_1000_8.yaml) |

建议固定顺序：**P0 → P1 → P2 → P3 → P3 → P2 → P1 → P0**。8 次完整回放按包时长约需 79 分钟，不包括构建、重启、冷却和证据检查。不要看到好结果就提前结束、丢掉坏轮或追加到“挑出最好一轮”为止。如果资源或代码身份异常导致一轮无效，记录原因，按事先定义的无效轮规则处理。

保持 `scaleFactor=1.2`、FAST 20/7、3 个执行者、`fps=10`、全部内参/基线/深度比例、`ThDepth=40`、精确优化和局部地图模式不变。配置文件只改变 nFeatures/nLevels，可使用 [experiment_matrix.csv](experiment_matrix.csv)登记；文件中的状态均为未测试。

以相同源序号比较总体和固定窗口，使用每轮完整输入集合。固定诊断窗口建议：23–100（首次下降/清图）、640–710（空 BoW 附近）、1320–1420（重定位保护）、2180–2270 与 3380–3470（小地图重置）、5000–5220（末段恢复反复）。其作用是解释原场景，不要求新版本仍在相同帧失跟。

## D. 通过第一轮后，再改变深度/建图策略

**D1：近点分界单变量。** 在第一轮表现稳定且时延可接受的配置上，比较 YAML 中的 `Stereo.ThDepth: 40.0` 与 `Stereo.ThDepth: 80.0`，其余不变，各两次交错完整回放。保留小数格式，冻结版参数读取器会拒绝整数节点。先确认 2–4 米实际深度质量，并记录近点数量、真实新增地图点数、点寿命、关键帧队列和地图增长。若仅提高 KF 数、耗时和错误位姿而没有持续跟踪收益，停止该方向。暂不直接从 40.0 跳到 120.0。

**D2：输入深度质量单变量。** 核验 65535 含义，进行已知距离目标/重复平面的深度检查，并统计真实板端内外点的深度和残差。再决定是否做最大范围或置信度过滤。8 米和 12 米只是待评估候选，不能预先称为可靠范围；对某些视角裁掉远点会使三维候选不足。过滤深度时保留 RGB 特征，使没有可信深度的点仍可参与允许的二维观测/后续多视图建点路径；验证实际行为，不假设所有路径自动转为单目约束。

`System.thFarPoints` 仅影响部分三角化/局部投影搜索，不能替代全链路输入处理。`DepthMapFactor` 是单位换算，不能作为深度截断开关。每次只引入一种策略，和未开启版本对照，不能同时改门槛、深度和特征数后归因。

**D3：只有观测支持时才改补点或匹配算法。** 若确认后续关键帧的有效新增点不足，可研究按可靠深度、空间覆盖和存活率选择补点，而非简单放松剔点。若投影搜索损失占主导，再评估运动预测和搜索窗；若优化大量拒绝，再检查深度误差、标定/时间对齐和残差模型。具体代码方案依赖 B 的证据，当前不预定“删掉某个保护条件”。

## E. 采集侧验证

使用稳定 USB 3 链路并记录真实 RGB/depth 时间、曝光和帧间隔。若重新录制同一路径的高帧率包，可从同一原始记录按时间一致地抽取 10/15 fps 对照，保持原始图像与真实时间戳；不要把旧 10 fps 包插帧或 2×播放当作新采集。

15 fps 周期约 66.7 ms，30 fps 约 33.3 ms。当前原配置回调 P95 已为 58.94 ms、P99 为 76.67 ms，均值 44.84 ms，因此不能假设板端增加特征后还能实时跑 30 fps。高帧率可能减小帧间运动，但会增加每秒计算需求；必须连同输入完成率、延迟和跟踪质量一起衡量。

可对新采集研究曝光上限和深度预设。官方 High Accuracy 预设提高深度置信要求但会降低填充率，不能假设它无条件优于 Default，也不能追溯改变已录好的 bag。[官方视觉预设说明](https://github.com/realsenseai/librealsense/wiki/D400-Series-Visual-Presets/5cd7f1fdbf662062c43c24fa89f4accb9f3e823f)

RGB-D+IMU 是单独方向：本包没有真实 IMU 流，不能仅改传感器模式来验证；需要重新采集、标定并检查时间同步。

## F. 结果筛选与停止条件

以下是**建议的试验筛选标准，不是已达成结果或现有项目硬门槛**：

| 维度 | 统计方式与建议 |
|---|---|
| 输入完整性 | 每轮 5878 对身份完全一致、全部完成；缺输入轮不能作为同条件质量提升的证据 |
| 持续跟踪 | 主要看 non-fresh 帧数、非 fresh 时间、连续 fresh 段长度和清图/新图次数；两轮方向一致，并超过 P0 自身波动 |
| 实用改善目标 | 初筛希望 non-fresh 帧数相对控制减少至少 30%，约从 1124 降至 787 或更少；同时新图与同 ID 清图总数应下降。该数字用于筛选，不替代精度检验 |
| 对应质量 | 在固定原始窗口查看实际阶段损失、内点低分位和空间覆盖；不能只算双方共同成功帧的平均内点 |
| 计算成本 | 10 Hz 下目标回调 P95 保持 <100 ms，P99 尽量 <100 ms，完整输入无新增缺失；同时核总延迟、长尾、后台队列和内存，不能只看均值 |
| 轨迹正确性 | 检查明显跳变、错误重定位和尺度异常；有真值时再计算 ATE/RPE/尺度误差，无真值时只能给诊断性质量结论 |
| 跨轮/跨场景 | 至少两轮重复；候选胜出后在独立场景验证。若同配置波动大于候选差异，结论为不确定 |

非 fresh 时间建议按原始时间区间加权：对每个非 fresh 输入累计到下一输入的时间差；最后一帧没有后继时单列结束截断，不补造时间。持续跟踪长度和首次失败时间只作为描述，不能把不同版本各自重置后的地图编号强行配对。

如果 P1/P3 提高点数却未降低失跟，或收益只来自降低接受门槛，应停止继续堆特征，转向已经测得的投影、优化残差或地图点存活问题。若加入观测或代码修复显著改变负载，先重建公平基线，再判断参数收益。
